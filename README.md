# Whispers of the Soul
Automatic production of three daily English spiritual YouTube Shorts (1080x1920, 35–55 s).
Script → textcheck → Kokoro narration + generative music + procedural visuals + captions → QC → GitHub release → Metricool schedule.
All visuals and music are generated by the code in `wots/`; voice: Kokoro-82M (Apache-2.0); fonts: SIL OFL. See CLAUDE.md.
